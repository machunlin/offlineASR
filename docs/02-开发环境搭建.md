# 开发环境搭建

## 1. 基础环境

- Java 11：使用开发机已安装的 JDK/JRE，不下载、不随应用包复制。
- Maven：3.8+，建议 3.9.x。
- Node.js：20，用于 JavaScript/SDK 契约和 Maven 清单脚本。
- FFmpeg：开发机通过系统包管理器安装；项目不下载或复制。
- Python 3：Linux/macOS 打包校验脚本计算 SHA-256 时使用。
- sherpa-onnx Native Runtime：仅在本机真实推理时由开发人员自行准备。
- 模型：仅在本机真实推理时准备 `2025-09-09` 版本。

优先使用 `JAVA_HOME`、`MAVEN_HOME`；构建统一使用 `-Dmaven.repo.local=.m2`，避免污染用户全局 Maven 缓存。

## 2. 外部运行依赖

开发构建只需要：

- `lib/sherpa-onnx-jvm-2.0.3.jar`：Java API/Wrapper，随 Fat JAR 构建。
- Maven 正常依赖。

真实推理还需要：

| 依赖 | 开发机位置 | 配置 |
|---|---|---|
| sherpa-onnx Native Runtime | `external/sherpa-onnx-native/` | `ASR_SHERPA_NATIVE_PATH` |
| SenseVoiceSmall INT8 | `models/SenseVoiceSmall/` | `ASR_MODEL_DIR` |
| FFmpeg | 系统安装或任意路径 | `ASR_FFMPEG` 或 `PATH` |

下载地址、SHA-256 和许可状态统一见 [第三方组件与许可证清单](08-第三方组件与许可证清单.md)。不得新增自动下载脚本，也不得把下列文件加入 Maven 依赖：

- `sherpa-onnx-native-lib-osx-aarch64-*.jar`
- `sherpa-onnx-native-lib-linux-x64-*.jar`
- `sherpa-onnx-native-lib-win-x64-*.jar`

Native JAR 必须扁平解压，目录根层放置两个库。例如 macOS：

```bash
mkdir -p external/sherpa-onnx-native
unzip -j sherpa-onnx-native-lib-osx-aarch64-2.0.3.jar \
  'sherpa-onnx/native/osx-aarch64/*' -d external/sherpa-onnx-native
```

## 3. 构建与测试

```bash
mvn -B -Dmaven.repo.local=.m2 clean test package
node scripts/verify-js-contract.mjs
node scripts/verify-sdk-contract.mjs
```

Fat JAR 检查：

```bash
jar tf target/offline-asr-0.1.0-SNAPSHOT.jar | grep -q 'BOOT-INF/lib/sherpa-onnx-jvm-2.0.3.jar'
! jar tf target/offline-asr-0.1.0-SNAPSHOT.jar | grep -Eq 'sherpa-onnx-native-lib-|onnxruntime|sherpa-onnx-jni'
```

Linux 应用包：

```bash
bash scripts/linux-package.sh
```

Windows 应用包：

```powershell
.\scripts\windows-package.bat
```

应用构建不再按平台切换 Maven Profile，也不把 Native 库写入 `target/`。

## 4. 本机真实推理

macOS ARM64：

```bash
export ASR_MODEL_DIR="$PWD/models/SenseVoiceSmall"
export ASR_SHERPA_NATIVE_PATH="$PWD/external/sherpa-onnx-native"
export ASR_FFMPEG="$(command -v ffmpeg)"
bash scripts/mac-start.sh
```

健康检查：

```bash
curl --fail http://127.0.0.1:8080/api/asr/health
```

未准备 Native、模型或 FFmpeg 时，应用允许启动，但 health 应为 `NOT_READY`，并给出对应缺失原因。

## 5. Maven 清单和 SBOM

```bash
bash scripts/generate-maven-inventory.sh macos-arm64
bash scripts/generate-maven-inventory.sh linux-x64
bash scripts/generate-maven-inventory.sh windows-x64
```

Windows PowerShell：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\generate-maven-inventory.ps1 -Label windows-x64
```

输出位于 `deploy/`。SBOM 只记录随应用构建的 Maven 构件；Native Runtime、模型、FFmpeg 和 Java Runtime 作为目标机外部依赖，不作为随包 Maven 构件。
