# 开发环境搭建

使用 SDKMAN Temurin Java 11 和 `/Users/chunlin/Documents/maven-3.9.16/bin/mvn`。为避免改动用户 Maven 缓存，执行命令均加 `-Dmaven.repo.local=.m2`。模型目录默认是 `models/SenseVoiceSmall`，可用环境变量覆盖；FFmpeg 可用 `ASR_FFMPEG` 覆盖。

运行测试：

```bash
JAVA_HOME=/Users/chunlin/.sdkman/candidates/java/current \
MAVEN_HOME=/Users/chunlin/Documents/maven-3.9.16 \
$MAVEN_HOME/bin/mvn -Dmaven.repo.local=.m2 test
```
