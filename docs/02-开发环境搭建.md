# 开发环境搭建

## 基础环境

- JDK：Java 11（Temurin/OpenJDK 均可）。
- Maven：3.8+，建议 3.9.x。
- Node.js：20，用于浏览器 SDK 契约检查。
- FFmpeg：本机安装并确保 ffmpeg、ffprobe 在 PATH 中。
- 模型：SenseVoiceSmall INT8，放入 models/SenseVoiceSmall/。

优先使用环境变量 JAVA_HOME、MAVEN_HOME；未设置时脚本会尝试从 PATH 和 SDKMAN 当前版本定位，不再依赖开发者个人绝对路径。为避免修改用户 Maven 缓存，构建命令使用 -Dmaven.repo.local=.m2。

## 构建与测试

macOS ARM64：

```bash
mvn -Pmacos-arm64 -Dmaven.repo.local=.m2 clean test package
```

Windows x64：

```powershell
mvn -Pwindows-x64 -Dmaven.repo.local=.m2 clean test package
```

Linux x64（先下载并校验官方原生库）：

```bash
bash scripts/download-linux-native.sh
mvn -Plinux-x64 -Dmaven.repo.local=.m2 clean test package
```

三个平台切换构建时必须执行 clean，避免上一次构建的 JNI 原生库残留在 target/ 中。
