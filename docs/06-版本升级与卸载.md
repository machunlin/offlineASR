# 版本升级与卸载

## 升级

1. 记录当前应用版本、模型哈希、配置和健康检查结果。
2. 停止前台服务或执行 WinSW stop。
3. 备份 config 和 logs；不覆盖客户确认保留的模型。
4. 核验新 app；模型、FFmpeg 和对应平台 Native Runtime 保持客户既有配置或按清单升级；Java 11 使用目标机已安装版本。
5. 启动后检查 health，使用一条可追溯样本完成识别。
6. 失败时恢复上一版应用目录，保留客户既有外部依赖，并记录失败原因。

## 卸载

先执行 windows-uninstall-service.bat。默认不删除模型、配置和日志；删除应用目录、模型或日志前必须由现场负责人明确确认范围。
