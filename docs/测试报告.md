# 测试报告

## 已验证（2026-11-25，MacBook M1 Pro / macOS 26.4.1）

- Java 11.0.31、Maven 3.9.16、FFmpeg 9.0.1。
- sherpa-onnx v2.0.3 官方 JVM JAR 与 macOS ARM64 原生 JAR，哈希见 `验证记录.md`。
- 模型目录和官方中文 WAV 已做 SHA-256 对照；模型加载 1.744 秒，直接 Java API 推理 0.137 秒。
- Spring Boot 实际 health 返回 `200 READY`。
- 实际 multipart 上传 5.592 秒 `zh.wav`：文本“开饭时间早上9点至下午5点。”，解码 0.112 秒、推理 0.412 秒、总计 0.527 秒。
- 可执行 JAR 已检查包含 `BOOT-INF/lib/sherpa-onnx-jvm-2.0.3.jar` 与 `BOOT-INF/lib/sherpa-onnx-native-lib-osx-aarch64-2.0.3.jar`。以 `java -jar target/offline-asr-0.1.0-SNAPSHOT.jar` 启动后，health 返回 `200 READY`；再次上传同一 WAV 成功，解码 0.097 秒、推理 0.208 秒、总计 0.316 秒。
