# 客户现场调试手册

| 顺序 | 操作 | 正常结果 | 异常处理 |
|---:|---|---|---|
| 1 | wmic cpu get name、任务管理器检查内存/磁盘 | 已记录硬件 | 空间或内存不足先处理环境 |
| 2 | jdk\bin\java.exe -version | Java 11 | 替换已验证 Runtime |
| 3 | ffmpeg\bin\ffmpeg.exe -version | 显示版本 | 核验文件和路径 |
| 4 | scripts\windows-start.bat | 服务保持运行 | 查看控制台和 logs |
| 5 | scripts\windows-status.bat | READY / true / true | 核验模型、native JAR、FFmpeg |
| 6 | Windows 声音设置 | USB 麦克风有电平 | 检查驱动、接口、隐私权限 |
| 7 | Chrome 打开首页 | 可申请麦克风权限 | 检查 localhost 和 Chrome 权限 |
| 8 | 短语音录音 | 返回最终文字 | 记录请求 ID、耗时、错误码 |
| 9 | 数字、英文缩写、长语音 | 如实记录输出 | 不将单样本泛化为准确率承诺 |
| 10 | 断网重启 | READY 并能识别 | 检查遗漏的在线依赖 |

禁止将原始语音、完整识别文本、模型绝对路径或客户个人信息粘贴到普通日志和工单。支持信息仅保留请求 ID、文件大小、错误码、阶段耗时和经授权的脱敏截图。
