## 2026-11-25：最小 Java SenseVoice INT8 验证（macOS ARM64）

### 目标

验证“官方 Java API + 指定 SenseVoiceSmall INT8 模型 + 当前 macOS ARM64 原生库”能完成一次真实离线中文 WAV 识别。

| sherpa-onnx | v2.0.3 |
| 推理设备 | CPU（macOS ARM64 原生库） |

### 官方资产与核验

1. 官方 sherpa-onnx v2.0.3 Release：<https://github.com/k2-fsa/sherpa-onnx/releases/tag/v2.0.3>。
2. 官方 Java 示例：<https://github.com/k2-fsa/sherpa-onnx/blob/v2.0.3/java-api-examples/NonStreamingDecodeFileSenseVoice.java>。该示例使用 `OfflineSenseVoiceModelConfig`、`OfflineRecognizer`、`WaveReader` 和 `model.int8.onnx` / `tokens.txt`。
3. 该 Release 实际提供 `sherpa-onnx-jvm-2.0.3.jar` 和 `sherpa-onnx-native-lib-osx-aarch64-2.0.3.jar`；Maven Central 对原设计中的 `com.k2fsa.sherpa.onnx:sherpa-onnx-jvm` 查询结果为 0，因此正式项目不得引用这个不存在的坐标。
4. 两个官方 JAR 的本地 SHA-256：

| 文件 | SHA-256 |
|---|---|
| `sherpa-onnx-jvm-2.0.3.jar` | `ad69b6a54462ba3671782617b11d35975c8d6b7c84ae11765e3a06dd0c56c0e5` |
| `sherpa-onnx-native-lib-osx-aarch64-2.0.3.jar` | `9c85930bcf081eb285a324f0f97eec63054a2a6ba7baf47408b83683add2a675` |
| `sherpa-onnx-native-lib-win-x64-2.0.3.jar` | `26a9072f4a47be3a73bfbbba5f25e6e8b84b24734be651de2d480ae753ae6508` |

5. macOS 原生 JAR 已检查，包含 `sherpa-onnx/native/osx-aarch64/libonnxruntime.dylib` 和 `sherpa-onnx/native/osx-aarch64/libsherpa-onnx-jni.dylib`。
6. 因 GitHub 的完整模型归档下载停滞，模型由 ModelScope 镜像 `fuyuantech/fuyuan-sherpa-onnx-sense-voice-zh-en-ja-ko-yue-int8-2024-07-17` 下载。镜像归档 SHA-256 为 `7d1efa2138a65b0b488df37f8b89e3d91a60676e416f515b952358d83dfd347e`。解压后的 `model.int8.onnx` SHA-256 为 `c71f0ce00bec95b07744e116345e33d8cbbe08cef896382cf907bf4b51a2cd51`，与官方仓库 `csukuangfj/sherpa-onnx-sense-voice-zh-en-ja-ko-yue-2024-07-17` 提供的同一 INT8 对象哈希一致。

### 执行命令与结果

编译和执行项目内验证程序 `.validation/source/VerifySenseVoice.java`：

```text
javac 11.0.31
MODEL_LOAD_SECONDS=1.744
INFERENCE_SECONDS=0.137
SAMPLE_RATE=16000
TEXT=开饭时间早上9点至下午5点。
```

### 结论

**通过。** 当前 macOS ARM64 可使用 sherpa-onnx v2.0.3 官方 Java API、官方 macOS ARM64 原生库和经哈希核验的指定 INT8 模型进行一次离线中文语音识别。

### 边界

- 本结果只覆盖当前 Mac、JDK 11、官方随附中文样本、CPU 线程数 2。
- Chrome 麦克风、浏览器上传、Spring Boot 服务、并发/超时、长音频、断网重启和 Windows x64 均尚未验证。
- Windows DLL、Windows 服务、USB 麦克风、Visual C++ Runtime、客户现场 CPU 性能仍必须在目标 Windows 主机实测。
- Windows x64 原生 JAR 已于 2026-11-25 通过国内 GitHub 代理下载，并与 sherpa-onnx 官方 v2.0.3 checksum.txt 核验一致；该核验仅证明发布资产完整，不证明 Windows 运行时通过。
