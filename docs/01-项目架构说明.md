# 项目架构说明

浏览器仅在 `127.0.0.1:8080` 录音并上传。后端将文件写入项目 `temp/<requestId>/`，FFmpeg 转为 16 kHz、单声道 Float32 PCM，再交给启动时单次加载的 SenseVoiceSmall INT8。处理完成或失败均清理该请求目录。模型推理默认单路、CPU 2 线程；日志不记录音频和识别文本。

运行时依赖分为三层：

| 层级 | 内容 | 交付方式 |
|---|---|---|
| Java API/Wrapper | `sherpa-onnx-jvm-2.0.3.jar` | 作为 Maven system 依赖进入应用 Fat JAR |
| JNI Native | `sherpa-onnx-jni` | 客户从官方 2.0.3 Native JAR 安装到 `external/sherpa-onnx-native/` |
| ONNX Runtime Native | `onnxruntime` | 与 JNI 同目录，由客户自行安装 |

应用启动前将 `ASR_SHERPA_NATIVE_PATH` 映射为系统属性 `sherpa_onnx.native.path`。sherpa-onnx `LibraryUtils` 优先加载该目录中的 ONNX Runtime，再加载 JNI；因此 Native JAR 内的库必须扁平解压到目录根层。

SenseVoiceSmall INT8 模型和 FFmpeg 也由目标机自行准备。应用包只包含项目自身 JAR、配置、脚本、校验材料和文档，不包含 Java Runtime、Native Runtime、模型或 FFmpeg。固定版本、直接下载地址、SHA-256 和许可状态见 `docs/08-第三方组件与许可证清单.md`。
