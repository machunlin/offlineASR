# 项目架构说明

浏览器仅在 `127.0.0.1:8080` 录音并上传。后端将文件写入项目 `temp/<requestId>/`，FFmpeg 转为 16 kHz、单声道 Float32 PCM，再交给启动时单次加载的 SenseVoiceSmall INT8。处理完成或失败均清理该请求目录。模型推理默认单路、CPU 2 线程；日志不记录音频和识别文本。

运行时依赖为 Java 11、Spring Boot 2.7、sherpa-onnx v2.0.3 官方 JAR、FFmpeg。官方 JAR 不在 Maven Central，项目 `lib/` 保存经 SHA-256 核验的 macOS JAR；Windows 必须替换为对应官方 win-x64 原生 JAR。
