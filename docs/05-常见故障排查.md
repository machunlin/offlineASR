# 常见故障排查

- `SERVICE_NOT_READY`：模型、tokens 或 JNI/native 库加载失败；核验平台 JAR 与模型 SHA-256。
- `AUDIO_DECODE_FAILED`：确认 FFmpeg 可执行、输入文件真实可解码。
- `AUDIO_DURATION_EXCEEDED`：录音超过配置的 600 秒上限。
- `FILE_TOO_LARGE`：文件超过配置的 50 MB。
- 端口被占用：检查 8080 的本机进程后停止正确的应用实例。
- Chrome 无麦克风：检查 Windows 隐私权限、USB 设备和 `127.0.0.1` 的站点权限。
