# 常见故障排查

| 现象 / 错误码 | 根因范围 | 检查与处理 |
|---|---|---|
| SERVICE_NOT_READY | 模型、tokens、JNI/ONNX Runtime 或 FFmpeg 不可用 | 读取 health 的 `modelError`；核对 `ASR_MODEL_DIR`、`ASR_SHERPA_NATIVE_PATH`、两个 Native 文件和 `ffmpeg -version`。 |
| DLL/JNI 初始化失败 | Native 子目录层级错误、平台混用、VC++ Runtime 缺失 | 将 win-x64 Native JAR 的两个 DLL 扁平解压到目录根层；安装 VC++ x64 Runtime。 |
| UNSUPPORTED_MEDIA_TYPE | 输入非有效音频或 FFmpeg 不可启动 | 使用 ffmpeg -i 文件检查；不能只依据扩展名。 |
| AUDIO_DECODE_FAILED | 解码失败、无声道或 PCM 无效 | 检查 FFmpeg、文件大小和 USB 麦克风收音。 |
| AUDIO_DURATION_EXCEEDED | 解码后真实时长超过上限 | 缩短录音或经评估后调整配置。 |
| FILE_TOO_LARGE | 上传超过上限 | 缩短录音或调整限制后重测。 |
| PROCESSING_TIMEOUT | FFmpeg、排队或推理超时 | 查看 CPU/内存；保持单路识别，谨慎调整超时和线程。 |
| 8080 被占用 | 其他应用占用端口 | netstat -ano | findstr :8080；确认 PID 后才停止进程。 |
| Chrome 无麦克风 | 隐私权限、站点权限、设备问题 | 检查 Windows 隐私设置、Chrome 和 USB 输入电平。 |
| 服务无法启动 | Runtime、路径、WinSW XML 或权限错误 | 先用 windows-start.bat 前台运行成功，再安装服务。 |
