# 公开演示站点运维说明

公开体验地址：https://asr.ai-buy.uk/

本目录只用于项目维护者配置公开演示站点的 Nginx 反向代理，不属于客户本地部署流程。客户部署请阅读仓库根目录 README 中的 Windows / Linux 部署手册。

## Nginx 配置

- 站点配置模板：nginx/offlineasr-http.conf
- 域名：asr.ai-buy.uk
- 上游：本机 Spring Boot 服务 127.0.0.1:8080
- 上传大小限制：60 MB
- 代理读写超时：660 秒

上线或修改前，先检查 DNS、TLS 证书、现有 Nginx 站点和应用监听地址；备份现有配置，执行 nginx -t，通过后再 reload。

## 安全

- 不要把 TLS 私钥、证书私钥、服务器密码、SSH 配置或环境变量提交到仓库。
- 应用默认不提供身份认证，不要直接将 8080 暴露到公网。
- 演示站点仅用于功能体验，不要上传客户语音、个人信息或其他敏感音频。
- 不要将演示站点的 Nginx 配置直接复制到客户现场，除非其网络拓扑确实需要反向代理。
